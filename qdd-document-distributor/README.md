# QDD 文档分发

轻量文档分发管理工具：多目录扫描、按类型与关键词自动分类、多条件筛选、全类型在线预览（图片/PDF/Word/Excel/PPT/文本/音视频）、批量打包下载、Excel 导出、文件上传，内置多用户与目录授权，适合团队在 NAS 上共享与分发资料。

首次安装默认管理员账号 `admin`，密码 `admin123`，登录后请立即修改。

## 功能

- 多目录扫描 + 自动分类（按文件类型与自定义关键词规则）
- 多条件筛选（类型 / 关键词 / 目录）
- 全类型在线预览（图片、PDF、Word、Excel、PPT、文本、音视频）
- 批量打包下载（ZIP）、Excel 导出、单文件下载
- 文件上传（写入允许目录）
- 多用户 + 目录级授权
- 支持三种访问模式：桌面 iframe、局域网 IP + 端口、飞牛中继子域名（公网自动走网关）

## 访问端口

默认监听 `9585`（IPv4 + IPv6 双栈）。桌面入口由 fnOS 应用中心数据库管理，保证局域网直连、中继子域名、公网域名三种入口统一可用。
