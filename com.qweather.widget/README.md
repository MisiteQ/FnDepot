# 时钟天气 QTWeather

飞牛 fnOS 桌面**时钟 + 天气**小部件（FPK 原生应用）：直接注入飞牛桌面显示，**无窗口标题栏**。卡片为大号时钟（时:分 + 秒 + 公历 + 农历干支）与实时天气 / 未来 5 天预报，**两个模块可独立开关**；点击飞牛「已安装」中的应用图标打开**设置中心**（独立窗口），支持全球城市搜索、自动刷新间隔、自由拖动、卡片背景透明度（**0% 可全透明**）、文字 / 图标 / 定位配色、**字号 50%–200%** 与**自定义字体上传**。设置保存到 NAS 后卡片**数秒内热生效，无需刷新桌面**。数据来源 [Open-Meteo](https://open-meteo.com/)（免费，**无需 API Key**），前端直连，无需经 NAS 网关中转。

## ✨ 功能

- **🧩 模块独立开关**：时间日期与天气预报可分别显隐（只看时钟、只看天气或两者都显，不能同时关）
- **🕐 时钟 · 农历**：大号时钟（时:分 + 秒，每秒走字）、完整日期星期、农历日期含干支年 / 日与闰月
- **🌤️ 实时天气**：温度、体感、湿度、风速、气压、天气状况（WMO 代码 → 离线内联 SVG 图标，夜间显示月亮）
- **📅 5 天预报**：每日天气图标与最高 / 最低温，窄宽度自适应折行不溢出
- **🪟 设置中心独立窗口**：点击飞牛「已安装」中的图标打开，桌面卡片只展示信息、不含任何设置入口
- **⚡ 保存即热生效**：卡片每 4 秒轻量轮询 NAS settings.json，保存后免刷新生效
- **🔍 城市切换**：内置中国行政区划坐标库（省 / 市 / 县 3200+，来源阿里 DataV）本地秒搜，国际城市直连 Open-Meteo
- **🔄 自动刷新**：10 / 30 / 60 / 180 分钟可选（默认 30 分钟）
- **🎚️ 背景透明度**：下限 0% 可真正全透明，磨砂 / 投影 / 分隔线同步淡出，文字图标始终不透明
- **🎨 三色配色**：文字、图标、定位针三个取色器，设置中心右侧实时预览
- **🔠 字号与字体**：字号 50%–200%；支持上传 ttf/otf/woff/woff2 自定义字体（≤25MB，保存在 NAS，可恢复默认）
- **ℹ️ 关于与更新检查**：内置关于页，自动 / 手动向 GitHub Releases 检查新版本（仅提示，不自动安装）
- **🖱️ 自由拖动缩放**：整卡可拖，最小尺寸 240×120

## 📦 安装

在 FnDepot 客户端中添加本应用源后，搜索「**时钟天气**」或「**QTWeather**」安装即可；安装完成后卡片即显示在飞牛桌面上（若未显示，强制刷新桌面 `Ctrl+Shift+R`）。

> 应用以 root 身份运行，以操作 nginx 配置与系统恢复包实现桌面注入。应用内部标识为 `com.qweather.widget`（沿用旧版），可由旧版「天气预报」直接覆盖升级，设置与位置不丢失。

## 🔒 隐私

- 天气数据由浏览器前端直连 [Open-Meteo](https://open-meteo.com/) 公开 API 获取，**不经过 NAS 中转、不上传任何个人信息**
- 所有设置（城市、位置、外观等）只保存在 NAS 本机 settings.json，不写入浏览器存储
