# QLink2Desktop (qlink2desktop)

把本机端口、Docker 容器、局域网或公网服务，一键放到飞牛 fnOS 桌面——注册成飞牛原生桌面应用，从桌面图标直接打开。

## ✨ 功能

- **本机端口 / Docker 自动发现**：流式解析内核套接字表 + Docker API，勾选即可一键上桌面
- **反向代理**：局域网、公网服务统一代理成本机端口，支持连通测试、可忽略自签证书
- **SSH 隧道**：其它机器（另一台 NAS、软路由、树莓派）上的服务也能放到桌面
- **网页快捷方式**：纯网页直接生成桌面入口，经飞牛 CGI 跳转，不受桌面入口主机限制
- **文字图标生成器**：无图可用时内嵌点阵字模现场生成一枚
- **Watchcow 兼容**：直接识别 Docker Compose 的 watchcow 标签，一键启用
- **主题与体验**：白天 / 暗黑 / 跟随系统，六套色系；面板内一键重启本应用服务
- **零端口占用**：通过飞牛统一网关（Unix Domain Socket）接入，不占任何 TCP 端口
- **安全卸载**：只清理本应用命名空间下的包，绝不触碰用户的其它应用

## 📦 安装

在 FnDepot 客户端添加本应用源 `https://github.com/MisiteQ/FnDepot` 后，搜索「QLink2Desktop」一键安装即可。

- 以 root 身份运行，最低 fnOS 版本 **0.9.0**
- 访问走飞牛统一网关（`/app/qlink2desktop`），**不占用任何端口**，不会与其它应用冲突
- 如需局域网直连调试，可在启动环境里设置 `PORT` 环境变量

## 🚀 使用

1. 从桌面打开 **QLink2Desktop**
2. 进入「发现 → 本机端口 / 容器标签」，勾选正在运行的服务，点启用
3. 回到飞牛桌面即可看到新图标，点开即用

「局域网扫描」可发现同网段其它主机的服务；「远程主机」可通过 SSH 隧道把远端机器上的服务也放到桌面。
