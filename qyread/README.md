# 惬意阅读 (QYRead)

飞牛 fnOS 上的私人书库与阅读中心（FPK 原生应用）：**搜书、管书、看书一站搞定**。所有书籍与数据仅保存在 NAS 本机，不上传第三方服务器。

> 基于「落地长安 轻阅读」改造，小说搜索下载模块整合了 [zsyo/go-novel](https://github.com/zsyo/go-novel) 的书源与爬虫逻辑，感谢两位作者的开源分享。

## ✨ 功能

- **📚 多格式书库**：支持 TXT / EPUB / MOBI / AZW3 / PDF / CBZ / CBR / CB7，拖拽批量导入，自动识别书名、作者、出版社；书架支持大封面 / 中封面 / 小封面 / 详细列表四种视图（详细列表显示作者、读到的章节与阅读进度），公共书库 + 个人书库、收藏夹、搜索排序与阅读统计；安装向导可直接指定 NAS 中已有的书籍文件夹，装好即可阅读
- **🔍 小说搜索下载**：聚合多个第三方书源搜索小说，一键下载 EPUB / TXT 并自动入库；下载文件夹可自由选择（默认下载到已设置的书籍文件夹，也可浏览存储盘新建个人书库）；全局任务面板实时显示阶段与百分比进度，支持**暂停 / 继续 / 取消**，刷新页面自动恢复，书源卡死的幽灵任务 60 秒内自动判失败并清理；已下载文件支持另存、删除与一键打开所在文件夹
- **📖 沉浸阅读**：目录导航、仿真翻页 / 上下滚动、字体字号行距边距与多款主题，切换主题时非阅读区外壳背景同步跟随；划线高亮、批注笔记，阅读进度自动保存
- **🔊 听书**：默认 Edge 在线语音（晓晓、云希等多种音色，无需下载模型），保留本地离线引擎入口
- **📝 读后感**：随时撰写整书心得，自动统计字数与累计阅读时长

## 📦 安装

在 FnDepot 客户端添加本应用源 `https://github.com/MisiteQ/FnDepot` 后，搜索「惬意阅读」一键安装即可；安装后从桌面打开，或直接访问 `http://<NAS_IP>:8344`。

- 默认端口：**8344**（安装向导可改）
- 默认账号：**admin / admin123**（登录后请及时修改）
- 应用以 package 身份（`qyread` 用户）运行，最低 fnOS 版本 **1.1.8**，依赖应用中心 Node.js v22

## 🔒 隐私

数据库、配置与书籍文件全部保存在 NAS 本地；JWT 密钥首次启动随机生成；仅在你主动搜索小说时访问第三方书源。搜索结果来自第三方书源，内容版权归原作者所有，本功能仅供学习交流，请支持正版。
