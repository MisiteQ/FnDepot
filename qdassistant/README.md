# QDAssistant 签到助手

飞牛 fnOS 上的「签到助手」（FPK 原生应用）：把 WorkBuddy 与 Trae 两个平台的每日签到搬到 NAS 上 **7×24 常驻**，到点自动完成，不用再每天打开电脑、打开两个软件手动点。纯 Python 标准库 + 单文件前端，**零第三方依赖**，凭据只保存在 NAS 本机。

## ✨ 功能

- **WorkBuddy 签到**：调用 `daily-checkin` 完成签到；token 失效自动刷新后重试（带 `refresh_token` 时），惰性刷新避免无谓请求；每账号在签到窗口内错峰到点触发
- **Trae 签到**：先 `status` 预检，已签则跳过不再打扰上游，未签才 `claim` 领取；网络异常自动重试，业务失败进冷却（401 永久 / 429 短冷却 / 5xx 渐进），积分三层兜底
- **多种凭据录入**：双平台均支持 **OAuth 登录** 与 **手动粘贴**（WorkBuddy `access_token` / Trae `JWT`）；Trae 还支持把本机客户端 `storage.json` 整段粘贴导入，服务端用纯标准库 AES-128-CBC 解密出 JWT + `refresh_token` 入库 —— NAS 上没有桌面客户端也能完成授权
- **凭据自动续期**：WorkBuddy token 惰性刷新；Trae JWT 过期前用 `refresh_token` 换新，界面显示剩余有效期并提前告警
- **后台 7×24 调度**：可配置每日签到时间段（如 09:00–12:00），窗口内每账号按 (日期, 账号) 确定性抽一个分钟；另有巡检间隔兜底补签与失败恢复
- **积分 / Token 统计**：两平台余额、积分包与到期进度；官方请求用量与会话 Token 用量（今日 / 近 7 天 / 本月，按账号 / 模型构成），10 分钟缓存可强制刷新
- **一键签到**：双平台全部账号并行触发，结果统一展示，他处已签自动补回执
- **Web 管理界面**：总览 / 签到 / 设置 / 关于 四个页面，手机与桌面自适应
- **配置导出 / 导入**：把全部已添加账号与签到策略导出成 JSON，换 NAS 直接导入免重新登录（导出不含监听地址 / 端口 / 口令）

## 📦 安装

在 FnDepot 客户端添加本应用源 `https://github.com/MisiteQ/FnDepot` 后，搜索「签到助手」一键安装即可；安装后从桌面打开，或直接访问 `http://<NAS_IP>:8790`。

- 默认端口：**8790**（Web 面板与 API 共用）
- 运行身份：**应用自身用户（package，无需 root）** —— 只读写自己的数据目录，不碰系统硬件、Docker 或其他应用
- 最低 fnOS 版本 **0.9.0**，适用 **x86 / arm64**

## 🔑 添加账号

- **WorkBuddy**（设置页 → WorkBuddy）：点击生成 OAuth 授权链接，在任意设备浏览器完成授权，服务端自动轮询入库；或手动粘贴 `access_token`。档位选「国内版 cn」——国际版没有签到接口，会自动跳过。
- **Trae**（设置页 → Trae）：推荐「从 Trae 客户端导入凭据」——把装过 Trae 客户端并已登录的电脑上的全局存储文件 `storage.json` 内容整段粘贴进来即可；也可手动粘贴 JWT。

> Trae 的授权码交换带设备签名校验，完整链路需要本机 Trae 客户端的设备私钥，NAS 上不存在该客户端，因此推荐直接用 `storage.json` 导入或手动粘贴 JWT。

## 🔒 隐私

- 数据目录默认 `~/.qdassistant`（fpk 安装时为应用 var 目录），账号 / 配置 / 日志全部为 JSON 文件，便于备份迁移
- 凭据脱敏展示（仅首尾各 4 位），日志不落 token / JWT
- 状态变更接口需携带 `X-QD-Request: 1` 请求头（CSRF 闸）
- 纯 Python 标准库实现，零第三方依赖；除签到接口与 OAuth 授权外不与任何外部服务通信
- **建议开启访问口令**（设置页），尤其 NAS 对局域网或公网开放时
