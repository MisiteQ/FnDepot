# 飞牛监控 (fnMonitor)

飞牛 fnOS 系统监控应用（FPK 原生应用）：实时监控 **CPU / 内存 / 磁盘 / 网络 / 温度 / 功耗 / GPU**，支持 Docker 容器管理、端口占用、硬盘 SMART、历史趋势与七套主题。纯 Python 标准库 + 单文件前端，**零第三方依赖、完全离线可用**，数据仅保存在本机。

## ✨ 功能

- **🏠 总览仪表盘**：状态卡片（CPU / 内存 / 存储 / 网络 / 温度 / 负载 / 运行时间 / IP）、时间·农历与天气、资源详情（每核 CPU / 内存明细 / 磁盘 IO）、硬盘信息（逐盘 SMART + SATA 告警计数）、硬件与传感器（内存插槽 SPD / 温度墙 / 电压 / 风扇）、实时功耗（Intel RAPL）与显卡监控、八维历史趋势折线图、进程 TOP
- **📊 流量统计**：整机 / 网卡 / 容器上下行流量、今日 / 本月 / 开机累计、容器流量排行、累计趋势图、CSV 导出（可排除 Docker 网桥）
- **⚡ 功耗统计**：实时瓦数 + kWh 耗电量 + 电费估算、累计趋势、硬盘休眠状态；无 RAPL 时自动回退 TDP 估算模型（可配置 TDP / 电价 / 单盘 / 网卡功耗）、CSV 导出
- **🐳 Docker · 端口**：容器列表与资源占用、一键启动 / 重启 / 停止、端口占用（应用 / 容器 / 系统监听）、内置应用统计（相册 / 影视 / 音乐）
- **⚙️ 设置**：监听端口、采集间隔、历史保留天数、数据导出（CSV / JSON）、一键健康报告（HTML）、飞牛桌面打开方式（窗口内嵌 / 浏览器新标签页）
- **🎨 界面**：七套主题、现代 NAS 仪表盘风格（侧边栏可收起）、每个面板 / 小模块独立显示隐藏、拖动排序自动记忆、手机端底部导航自适应

## 📦 安装

在 FnDepot 客户端中添加本应用源后，直接搜索「飞牛监控」安装即可；安装后桌面打开 **飞牛监控**，或直接访问 `http://<NAS_IP>:8777`。

> 应用以 root 身份运行，以支持风扇控制（sysfs 写入）、Docker 容器监控（docker.sock）、硬盘健康 / 温度（smartctl 裸设备访问）与跨用户进程 / 端口检测。

## 🔒 隐私

所有数据（历史 / 界面设置 / 配置）均保存在 NAS 服务器端本地，完全离线可用，不上报任何数据。
